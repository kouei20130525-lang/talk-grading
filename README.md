# TALK BATTLE

声・話すペース・話し続けた時間などをブラウザ内で分析する、近未来デザインのトーク採点サイトです。

## 公開方法（GitHub Pages）

1. GitHubでこのリポジトリを開く
2. **Settings → Pages** を開く
3. **Build and deployment** の **Source** を `Deploy from a branch` にする
4. Branch を `main`、Folder を `/ (root)` にして **Save**
5. 数分後、`https://kouei20130525-lang.github.io/talk-grading/` で公開

## 機能

- 難易度別のお題（EASY / NORMAL / HARD）とランダム出題
- 30秒・60秒・90秒のトーク
- マイク録音と音声認識（対応ブラウザ）
- 声量、話すペース、発話量、継続性などの目安を使ったスコア
- 1対1バトル（同じお題で順番に挑戦）
- 音声データはページ内で処理し、サーバーには送信しない

## 注意

- マイク利用にはHTTPS接続とブラウザの許可が必要です。GitHub PagesはHTTPSに対応しています。
- ブラウザは過去の許可状態を記憶するため、毎回マイク確認を表示できるとは限りません。録音開始時には毎回マイク取得を要求します。
- 音声認識はブラウザ依存です。Chrome / Edge などでの利用を推奨します。
- 現在の採点は音声特徴と認識テキストを使った簡易的な目安です。AIによる意味理解や専門的な発音評価ではありません。
- 音声認識機能はブラウザの実装によって、認識処理が端末外のサービスを利用する場合があります。
